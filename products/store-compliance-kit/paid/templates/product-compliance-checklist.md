# قائمة فحص المنتج — قبل الاستيراد

> طبّقها على **كل** صنف. أي "لا" في القسم الأول = استبعاد فوري بلا نقاش.

## القسم أ — أصناف توقف الحساب (فشل واحد = رفض)

- [ ] **ليس مقلَّداً ولا مزوّراً** — السبب الأول لإيقاف الحسابات وحجز الأموال، بلا إنذار
- [ ] ليس مأكولاً ولا مكمّلاً غذائياً — مستنقع تنظيمي لبائع أجنبي
- [ ] ليس دواءً ولا جهازاً طبياً ولا يحتاج ادعاءً طبياً لبيعه
- [ ] ليس ضمن الأصناف المقيّدة في فئتك على المنصة *(اقرأ قواعد فئتك — لا تفترض)*
- [ ] ليس سلاحاً ولا أداة خطرة ولا مادة قابلة للاشتعال
- [ ] لا يحمل علامة تجارية أو شخصية أو شعاراً لا تملك حق استخدامه
- [ ] ليس منتجاً بالغاً ولا مقيّد العمر
- [ ] **لا يحتاج ادعاءً كاذباً لبيعه**

## القسم ب — قابلية الوصف والتسليم (فشل = أصلحه قبل الإدراج)

- [ ] **سلعة مصنّعة قياسية** — لا مستعملة ولا فريدة ولا "قطعة واحدة"
- [ ] أستطيع وصفها بدقة: خامة · أبعاد · وزن · لون/مقاس · كمية · وظيفة · محتويات العلبة
- [ ] أصفها **بمواصفتها لا بوحدة بعينها** — يبقي لي حرية التوريد إن أخلّ المورّد
- [ ] لها مخزون حيّ ومزامنة مفعّلة — الإلغاء من طرف البائع يوقف الحسابات
- [ ] أستطيع الالتزام بنافذة التوصيل المعلنة **لهذا الصنف تحديداً** (16 CFR 435)
- [ ] **أستطيع تحمّل كلفة إعادة شحنه أو رد ثمنه** إن ضاع — الأصناف الثقيلة والهشة ترفع هذه الكلفة كثيراً

## القسم ج — صدق العرض

- [ ] أستطيع بيعه **بادعاءات فيزيائية فقط** بلا مبالغة طبية
- [ ] لن أحتاج مؤقتاً وهمياً ولا سعراً مضخّماً
- [ ] **لن أحتاج تقييمات مشتراة أو محفَّزة** — 16 CFR 465، غرامات تصل $53,088 لكل مخالفة
- [ ] الصور تمثّل ما سيصل فعلاً *(احذر الصور المحسّنة التي تعِد بما لا يطابق — أكبر مصدر لمرتجعات "ليست كما وُصفت")*
- [ ] السعر الكلي شامل الشحن يظهر قبل الدفع

## القسم د — تجارياً (لا يخص الامتثال، لكنه يقرر بقاءك)

- [ ] بيانات مبيعات فعلية تثبت الطلب — لا "ترند" ولا حدس
- [ ] الهامش بعد **كل** الرسوم + احتياطي ٣–٥٪ لا يزال موجباً
- [ ] معدل العيوب منخفض — كل مرتجع يكلفك مرتين
- [ ] ليس موسمياً بشكل يقتل التدفق النقدي
